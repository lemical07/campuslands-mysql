# Resolucion del ejercicio 046 - CREATE TABLE para restaurante urbano

**Estudiante:** Selvin Lem  
**Nivel:** Basico retador

## Objetivo

Crear una tabla de menu para un restaurante de comida urbana y consultar sus productos.

## Proceso de ejecucion

Ejecutar `ddl/schema.sql`, `dml/inserts.sql` y `dql/consultas.sql` en ese orden desde MySQL.

## Decisiones tecnicas

Se usan `DECIMAL` para precios y `ENUM` para categoria y disponibilidad. Las restricciones validan precio y ventas estimadas.
