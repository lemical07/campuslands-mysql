# Resolucion del ejercicio 031 - CREATE TABLE para torneo esports MOBA

**Estudiante:** Selvin Lem  
**Nivel:** Basico aplicado

## Objetivo

Modelar equipos, jugadores y partidas de un torneo esports MOBA.

## Proceso de ejecucion

Ejecutar `ddl/schema.sql`, luego `dml/inserts.sql` y finalmente `dql/consultas.sql` desde un cliente compatible con MySQL.

## Decisiones tecnicas

Las claves foraneas relacionan jugadores y partidas con sus equipos. Las restricciones `CHECK` validan puntajes y cantidades de victorias.
