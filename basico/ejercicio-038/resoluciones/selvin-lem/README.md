# Resolucion del ejercicio 038 - UPDATE para futbol sala

**Estudiante:** Selvin Lem  
**Nivel:** Basico aplicado

## Objetivo

Actualizar la tabla de equipos de un torneo de futbol sala mediante sentencias `UPDATE` controladas.

## Proceso de ejecucion

Ejecutar `ddl/schema.sql`, `dml/inserts.sql` y `dql/consultas.sql` en ese orden desde MySQL.

## Decisiones tecnicas

Los `UPDATE` usan condiciones especificas por equipo. Las restricciones validan puntos, partidos y goles no negativos.
